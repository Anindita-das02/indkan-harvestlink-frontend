# INDKAN HarvestLink - Frontend

Responsive modern frontend for the INDKAN HarvestLink wholesale agricultural export platform, built with React, Vite, and TypeScript.

## Features
- **Commercial Landing Page:** Hero showcase, featured export commodities, international trade workflow, and compliance highlights.
- **Product Catalogue:** Real-time commodity search, category filtering, Sortex purity standards, and MOQ parameters.
- **Product Details:** High-resolution product showcase, FOB/CIF bulk quotation request action, and technical specifications.
- **Responsive Layout:** Optimized across desktop, tablet, and mobile viewports.

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Custom Vanilla CSS Design System
- **Icons:** Lucide React
- **API Client:** Axios / Custom API Service

## Development Setup

```bash
# Install dependencies
npm install

# Start local Vite dev server
npm run dev

# Build for production
npm run build
```
